## 2026-07-01（初回・過去分の遡り）

- `init: テレアポ切り返しAIアシスタント（引越し特化デモ）`（初回コミット）。
- 機能：顧客プロファイル（年代・物件種別・エリア）に応じた提案の出し分け、よくある断り文句のクイック選択、会話履歴を保持して深掘り。
- 提案の型＝**状況分析 → 切り返しトーク例 → ポイント解説 → 次の一手** の4段構成。
- 技術：Next.js 14 (App Router) / TypeScript / Tailwind / Anthropic Claude API（claude-sonnet-4-6）。

## 2026-07-09（公開デモ用「サンプルモード」を実装）

**背景**：ポートフォリオの実績のうち本デモは**GitHubリンクのみ**で、動くURLがなかった（`計画\04_ポートフォリオ計画.md`）。公開してLLMを直接叩かせるとAPIコストが青天井になるため、RAGデモと同じ「サンプルモード」を入れた。

**やったこと**
- `lib/demo.ts` を新設：`DEMO_MODE`（`NEXT_PUBLIC_DEMO_MODE=1`）／`SAMPLE_ANSWERS`（既存 `QUICK_PHRASES` の6つの断り文句に対応）／`DEMO_FALLBACK`
- `app/api/chat/route.ts`：デモモードなら最後のユーザー発話をキーに固定応答を12ms/文字でストリーム返却。**LLMのストリームと同じ体感**
- **`new Anthropic()` をモジュールスコープから遅延生成に変更**。APIキーを持たないデモ環境では import 時点で例外になるため（デプロイ前に踏むと原因が分かりにくい）
- UI：ヘッダーに「公開デモ（回答は固定応答）」バッジ
- **入力欄下のヒント文を切り替え**。「顧客プロファイルを設定するとより精度の高い切り返しが生成されます」は固定応答では嘘になるので、デモモードでは「プロファイルは反映されません」と明記

**サンプル回答の中身**：`SYSTEM_PROMPT` に書いてある切り返しの基本パターンから起こしたので、実際のツールが返す内容と方向が一致する。「もう一手」も各文句に付けた。

**検証**：`tsc --noEmit` → `NEXT_PUBLIC_DEMO_MODE=1 next build` → `next start` で実機確認。「もう他の業者に頼みました」でおすすめトーク＋もう一手が1文字ずつ流れることを目視。

**残り**：デプロイ時に `NEXT_PUBLIC_DEMO_MODE=1` をビルド前の環境変数に設定する。

## 2026-07-09（Phase 2：レスポンシブ対応）

`sm:`/`md:` の指定が**ゼロ**で、サイドバー `w-64` 固定＋横並び flex のため、スマホでは確実に破綻する状態だった（`計画\04_ポートフォリオ計画.md` Phase 2-5）。

- コンテナ: `flex` → `flex flex-col md:flex-row`（スマホは縦積み）。`overflow-hidden` → `min-h-0 overflow-y-auto md:overflow-hidden`（縦積み時にページ全体でスクロールさせる）
- サイドバー: `w-64` → `w-full md:w-64`、境界線を `border-r` → `border-b md:border-b-0 md:border-r`
- 顧客プロファイルの3つのselect: スマホは `grid grid-cols-3` に畳んで縦の占有を削減
- 断り文句のボタン: スマホは `flex-wrap` のチップ、md以上は縦積み
- ヘッダー: `px-6 py-4` → `px-4 md:px-6 py-3 md:py-4`、バッジは `flex-wrap`
- チャット領域: `px-6 py-6` → `px-4 md:px-6 py-4 md:py-6`、`min-h-0` を追加

**検証**：`tsc --noEmit` → `next build` → `next start` でデスクトップ表示が崩れていないことを確認。
⚠️ **スマホ幅の目視は未実施**。ブラウザ自動化の `resize_window` ではviewportが変わらず検証できなかった。**実機確認は週末PCバッチへ**。
