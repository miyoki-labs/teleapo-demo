# テレアポAI 知識格納ガイド

知識の格納・編集はすべて `app/api/chat/route.ts` の `SYSTEM_PROMPT` を直接編集します。

---

## ファイルの場所

```
app/
└── api/
    └── chat/
        └── route.ts  ← ここだけ編集する
```

---

## システムプロンプトの構成

`SYSTEM_PROMPT` は以下の4ブロックで構成されています。

```
1. 基本役割（冒頭の説明文）
2. 引越しテレアポの基本知識
3. よくある断り文句と切り返しパターン  ← 最もよく追加するブロック
4. 顧客プロファイル別のポイント
5. 回答フォーマット（変更不要）
```

---

## 断り文句パターンを追加する

`【よくある断り文句と有効な切り返しの基本パターン】` のブロックに追記します。

**フォーマット：**

```
「断り文句のテキスト」
→ 「切り返しトーク例1」
→ 「切り返しトーク例2（任意）」
```

**追加例：**

```
「担当者が変わりました」
→ 「ご連絡が重なってしまい失礼しました！改めまして、○○引越センターの田中と申します。新しいご担当の方にもぜひ一度お話を聞いていただけますか？」
```

---

## 顧客プロファイル別のポイントを追加する

`【顧客プロファイル別のポイント】` のブロックに追記します。

**フォーマット：**

```
- 条件：強調すべきポイントを一文で
```

**追加例：**

```
- 法人・単身赴任：会社負担の場合は領収書対応・法人割引の有無を確認してアピール
```

---

## クイック選択フレーズを追加する

断り文句のボタンを追加する場合は `app/page.tsx` の `QUICK_PHRASES` 配列に追記します。

```typescript
const QUICK_PHRASES = [
  "もう他の業者に頼みました",
  // ↓ ここに追加
  "担当者が変わりました",
];
```

---

## 変更してはいけない箇所

| 箇所 | 理由 |
|------|------|
| `【回答フォーマット】` ブロック | AIの出力形式が崩れる |
| `model:` の値 | 速度とコストのバランスで選定済み |
| `max_tokens: 1024` | 切り返しトーク用途に最適化済み |

---

## よくある失敗と対処

**AIが長い回答を返すようになった**
→ `【回答フォーマット】` の末尾に `余計な分析・解説は不要です。` が残っているか確認する

**特定の断り文句に対して的外れな回答が返る**
→ `【よくある断り文句と有効な切り返しの基本パターン】` にそのケースを明示的に追加する
